# 智算网络方向小组学习资料库

智算网络方向小组的学习沉淀仓库：按周整理学习笔记、阅读材料、思考题与实验记录。

> **分工约定**：GitHub 承载**结构化笔记、代码、脚本**等学习沉淀；**飞书文档**用于日常协作与讨论，定稿内容沉淀到本仓库。

## 目录结构

```text
learning-repo/
├── README.md                # 仓库总说明（本文件）
├── schedule.md              # 总学习计划表：每周主题、时间、目标
├── resources/               # 公共原始资料（子目录按需创建）
│   ├── books/               #   电子书、教材（建议只放链接，见下方约定）
│   ├── papers/              #   论文
│   ├── slides/              #   课件、PPT（建议只放链接）
│   ├── skills/              #   Agent 技能包（画图：drawio-skill、drawio-styles）
│   ├── links.md             #   外部链接合集：文档、视频、博客
│   └── tools/               #   环境搭建脚本、配置文件
├── notes/                   # ✅ 核心：按周划分学习内容（子目录按周陆续创建）
│   ├── note01/
│   │   ├── topic.md         #   本周主题、学习方向、思考题
│   │   ├── shared/          #   小组共同产出（集体笔记、讨论纪要）
│   │   ├── exercises/       #   练习题、代码作业、实验
│   │   └── personal/        #   每人一个文件夹，放个人笔记/草稿
│   ├── note02/
│   └── ...
```

## 每周学习流程

1. 确定本周主题，登记到 [schedule.md](schedule.md)；
2. 在 `notes/` 下新建 `noteNN/`（两位数字编号：note01、note02……）；
3. `topic.md` 写清本周主题、学习方向和思考题；
4. 学习过程中：个人笔记放 `personal/<你的名字>/`，集体产出放 `shared/`，练习与实验放 `exercises/`；
5. 有公共资料（论文、视频、博客等）统一收录到 `resources/links.md`。

## 协作约定

- **个人文件夹**（`personal/<名字>/`）仅本人维护，格式、内容不强制统一；
- `shared/` 与 `exercises/` 中的内容建议注明作者和日期，方便回顾；
- 本仓库为**公开仓库**，请勿上传受版权保护的教材、课件等文件，改以链接形式记录；大文件（数据集、模型权重等）也请使用网盘/外部链接；
- 提交信息建议简洁说明内容，如 `notes: 补充 note01 集体讨论纪要`。
