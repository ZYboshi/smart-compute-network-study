# nn-textbook 构图惯例（神经网络/模型结构图专用）

> 来源：《机器学习》第 5 章 神经网络课件（SWJTU）。预设 JSON（`presets/nn-textbook.json`）
> 只能存通用配色/形状/字体，本文件记录 schema 放不下的绘图惯例。
> **激活 nn-diagram-style 后、生成任何 XML 前必读；与预设 JSON 冲突时以本文件为准。**

## 核心原则

**节点永远是白底圆，颜色只出现在三处**：浅绿层背景、橄榄绿参数标签、砖红高亮路径。
绝不给神经元填绿色/红色。

## 惯例明细

- **神经元**：`ellipse;fillColor=#FFFFFF;strokeColor=#909090`，直径 40–44px；标签一律放在圆外，不写进圆内。
- **输入/输出标签**（x₁…x_d、y）：黑色斜体衬线 `fontStyle=2;fontFamily=Times New Roman`，x 标签放圆左侧，y 放输出箭头末端；下标用 HTML（`x&lt;sub&gt;1&lt;/sub&gt;`）。
- **参数标签**（w、b、θ）：橄榄绿斜体 `fontColor=#70A030;fontStyle=2`，贴近对应边/箭头放置。
- **偏置 b / θ**：从神经元正上方画一条短垂直向下箭头（`strokeColor=#70A030;endArrow=classic;endFill=1`，无端点节点，用 `sourcePoint` 几何），b/θ 标签绿色斜体放箭头旁。**纵向（TB）布局时镜像**：偏置箭头改为从左侧水平指入（`entryX=0;entryY=0.5`），标签放箭头上方——上方要留给层间连线。
- **连接边**：直线（`edgeStyle=none`）、`#909090`、`strokeWidth=1`、实心小三角箭头指向目标神经元；层间全连接时无需每条都标权重。
- **层高亮**：在该层神经元**后方**放浅绿矩形 `fillColor=#E0F0E0;strokeColor=none`（XML 中先于神经元声明以置于底层）；层名（如"输入层"）作为**独立文本单元**放在矩形正上方外侧：`fontStyle=1;fontSize=18;fontColor=#70A030;align=center`。
- **前向传播/反向传播高亮**：被激活的边与其 z/a 标签改砖红 `#B03030`，其余保持灰绿。
- **省略节点**：未画全的层用黑色 `⋮` 文本节点表示。
- **循环/自连接**（RNN 类）：用 `curved=1` + 同侧出入（如 `exitX=1;exitY=0.25` / `entryX=1;entryY=0.75`）加两个 waypoint 在神经元侧面画出弧形回路，循环权重标签（w 等）绿色斜体放弧外侧。
- **坐标轴/函数曲线**（如需要）：轴用细灰线 + 小箭头；曲线用橄榄绿 `#70A030`；渐近线用灰色虚线。

## 反例（不要这么做）

- 不要给神经元填任何颜色（绿/红都不行）
- 不要把层名写进矩形内部当 header——层名在矩形**上方**
- 不要用正交折线（orthogonal）连神经元——一律直线
- 不要把 w/b 标签做成黑色——它们是绿色斜体
